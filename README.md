# tampermonkey-scripts

Collection of Tampermonkey scripts.

## Install

1. Install the [Tampermonkey extension](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo).
2. Right-click the Tampermonkey icon → **Manage extension** → enable **Allow User Scripts**.
3. Left-click the Tampermonkey icon → **Dashboard**.
4. Drag and drop a script from this repo onto the dashboard.
5. Enjoy!
